# snow-flake-uz

Ish stolida qor yog'adi: Windows va macOS. Qor Dock/taskbar ustida uyum bo'ladi, kursor bilan supurib tashlasa bo'ladi.

## Ishga tushirish
```
npm install
npm start
```
Boshqaruv: menyu qatoridagi (mac) yoki tray'dagi (Windows) qor belgisi.

## O'rnatish fayli
```
npm run dist
```

## Sozlash
`renderer.js` tepasidagi `TUNE` ichida qor miqdori, uyum balandligi va shamol kuchi bor.
